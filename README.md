# Discord Server Builder

Внутренний инструмент, а не товар. Один бот, которого клиент приглашает к себе с правами администратора; по команде он разворачивает структуру сервера из пресета и настраивает AutoMod. После сдачи бота выгоняют — каналы, роли и права остаются.

Лоты, которые он закрывает: «Настройка сервера» (500 ₽) и «Создание сервера под ключ» (800 ₽) из [funpay-lots-discord.md](../funpay-lots-discord.md).

## Что бот делает и чего не делает

| Делает | Не делает |
|---|---|
| Категории, каналы, темы каналов | Не создаёт сервер за клиента — см. ниже |
| Роли: цвет, порядок, вынос в отдельную группу | Не переносит участников и сообщения |
| Права на каждый канал | Не загружает эмодзи и стикеры |
| Правила AutoMod на стороне Discord | |
| Приветствие, верификация, меню ролей, панель тикетов | |

**Создать сервер ботом нельзя.** Эндпоинт `POST /guilds` работает только для ботов, состоящих меньше чем в 10 серверах, и владельцем созданного сервера становится сам бот — передать владение человеку через API невозможно. Поэтому «под ключ» = клиент создаёт пустой сервер сам (или по ссылке-шаблону), а бот его наполняет.

## Схема пресета

Пресеты лежат в [presets/](presets/) — обычный JSON, правится без программиста.

### Роли

```json
{ "key": "mod", "name": "Модератор", "color": "#3498db", "hoist": true, "perms": "moderator" }
```

`key` — внутренний идентификатор, на него ссылаются каналы. `hoist` — показывать роль отдельной группой в списке участников. `perms` — набор прав, а не список флагов:

| Набор | Права |
|---|---|
| `admin` | Администратор |
| `moderator` | Удаление сообщений, кик, бан, тайм-аут, управление ветками, просмотр журнала |
| `member` | Писать, читать историю, файлы, ссылки, реакции, ветки, голосовые |
| `newbie` | Ничего сверх `@everyone`: видит только канал верификации |

### Каналы

```json
{ "name": "логи", "type": "text", "access": "staff", "topic": "Алерты AutoMod" }
```

`type` — `text`, `voice`, `announcement`, `forum`. `access` определяет права:

| Доступ | Кто видит | Кто пишет |
|---|---|---|
| `public` | все, включая непроверенных | участники |
| `read_only` | все проверенные | только staff |
| `members` | участники | участники |
| `staff` | модераторы и выше | модераторы и выше |

Дополнительно: `user_limit` для голосовых, `fallback` — чем заменить канал, если тип недоступен.

### Верификация, тикеты, AutoMod

```json
"entry":    { "channel": "вход", "grant_role": "member", "hidden_until_verified": true },
"tickets":  { "channel": "создать-тикет", "staff_role": "mod", "kinds": ["Вопрос", "Жалоба"] },
"automod":  { "spam": true, "mention_limit": 5, "block_invites": true, "log_channel": "логи" }
```

AutoMod работает на стороне Discord и **не требует хостинга**: правила живут на сервере клиента даже после того, как бота выгнали. Лимиты площадки: 6 правил по словам, по одному на спам, упоминания и профиль.

## Открытый вопрос: форумы и объявления

Каналы типа `forum` и `announcement` доступны только серверам с включённым режимом Community, а для него нужны канал правил и канал обновлений. Варианта два: включать Community самим перед сборкой или подменять такие каналы на обычные текстовые. В пресетах у них проставлен `fallback`, окончательное решение — при реализации.
